Проект реализует и тестирует консервативную LP-стратегию ETH/USDC: часть капитала направляется в Uniswap V2 LP, часть используется как collateral в Aave V3, после чего стратегия занимает WETH для частичного хеджирования ETH exposure. Мы сравниваем стратегию с buy & hold, plain LP и fixed hedge LP на исторических данных и Monte Carlo стресс-сценариях.
